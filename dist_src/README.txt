Avadon 2: The Corruption 日本語化パッチ __VERSION__
==========================================================

Spiderweb Software の RPG「Avadon 2: The Corruption」（Steam 版）を日本語で遊べるようにする非公式パッチです。
会話・本・クエスト・アイテム名・画面の文字・地名など、ゲーム内のほぼすべての文章を日本語にします。

紹介ページ: __PAGE_URL__


■ 対応しているゲーム
  Steam 版 Avadon 2: The Corruption（アプリ番号 233310）専用です。
  GOG 版・Humble 版など他のストアの版には対応していません。対応できない版では日本語化を自動で止め、
  英語のまま普通に起動します。


■ インストール
  ZIP の中身（dsound.dll、avadon2_jp.ini、avadon2_jp フォルダ）を、ゲームのフォルダ
  （Avadon 2.exe があるフォルダ）にそのままコピーするだけです。
  ゲームのフォルダは、Steam でゲームを右クリック →「管理」→「ローカルファイルを閲覧」で開けます。

  あとは Steam からゲームを起動してください。
  初回の起動時に、お手元のゲームのファイルから日本語版のデータを作り、avadon2_jp\cache フォルダに保存します。
  ゲームの元のファイルは書き換えません。

  このパッチには元のゲームのファイルは入っていません（日本語版との差分だけが入っています）。


■ アンインストール（元に戻す）
  ゲームのフォルダから dsound.dll、avadon2_jp.ini、avadon2_jp フォルダを削除します。


■ 設定
  avadon2_jp.ini で、日本語フォント（既定: メイリオ太字）・文字の濃さ・大きさ・位置などを変えられます。


■ うまく動かないとき
  ・英語のままの場合: avadon2_jp\avadon2_jp.log を開き、「not translated」と出ていないか確認してください。
    ゲームのファイルが元と違う（更新された、別のMODで変更されている）と、そのファイルは英語のままになります。
    Steam の「ゲームファイルの整合性を確認」を実行すると直ることがあります。
  ・英語のまま起動する場合は、avadon2_jp\avadon2_jp.log に「NOT as expected」と出ていないか確認してください。
    お使いの Avadon 2.exe に対応できなかったことを示します（ゲームの更新や、他のストアの版など）。


■ 注意
  ・起動時の設定ダイアログ（画面モードの選択）と、タイトル画面・メニューなどの画像の中の文字は英語のままです。
  ・英語版で作ったセーブデータを読み込むと、セーブに記録済みの文字（メモやログなど）は英語のまま表示されることがあります。
    新しく始めるのがおすすめです。
  ・誤訳や不自然な箇所、表示の崩れがあれば GitHub の Issues でお知らせください。
  ・ベータ版です。誤訳や表示の崩れが残っていることがあります。
